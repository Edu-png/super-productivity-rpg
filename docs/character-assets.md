# Character assets

The RPG profile renders characters by composing transparent PNG layers on a shared
64x64 canvas. `CharacterRendererComponent` never draws body parts procedurally.

The current high-quality class presets use **Ocean's Nostalgia - MZ Heroes** by
Ocean's Dream. The original terms are bundled at
`src/assets/characters/oceans-nostalgia/LICENSE.txt`. These sprites require
ownership of the original RPG Maker MZ RTP. They are selected by class and gender
and cropped directly from the original animation sheets.

## Adding an asset

1. Export a transparent 64x64 PNG without resampling.
2. Align its feet to anchor `(32, 58)`.
3. Put it in the matching folder under `src/assets/characters/`.
4. Add an entry to `src/assets/characters/manifest.json`.
5. For hair, provide both `back` and `front` paths.
6. Add compatibility metadata for body and species when the asset is restricted.
7. Reference the asset ID from a class loadout or an inventory item's
   `spriteAssetId`.

The render order is controlled exclusively by `manifest.json`. Changing an equipped
item only invalidates the character composition; decoded images remain cached by
`CharacterSpriteLoaderService`.

## Current placeholder pack

The PNG files generated by `tools/generate-rpg-placeholder-assets.ps1` are original,
temporary development art. They establish alignment, transparency, equipment
integration, class silhouettes, and the full rendering pipeline, but should be
replaced by final production art.

Production sprites still needed:

- distinct slim, standard, and strong bodies for every species and gender;
- a dedicated fae body instead of the elf-compatible fallback;
- afro, bun, ponytail, mohawk, braids, dreadlocks, and wavy hair;
- stubble, goatee, moustache, long and viking beard variants;
- additional eyes, noses, mouths, scars, tattoos, earrings, horns, and glasses;
- unique bard, merchant, guardian, and necromancer clothing and weapons;
- helmets, capes, gloves, quivers, spell books, holy symbols, rings, and amulets;
- rarity-specific inventory sprites and full idle/walk animation sheets;
- palette variants for skin, hair, eyes, cloth, metal, and accessories.

Do not add full precomposed character combinations. Every new visual must remain an
independent transparent layer.
